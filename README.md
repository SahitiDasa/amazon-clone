# Amazon Homepage Clone

A web-based recreation of Amazon's e-commerce homepage, featuring a structured shopping interface with intuitive navigation, a prominent search section, promotional banner, and product category layouts.

## ✨ Overview

The application recreates the visual experience of an e-commerce homepage through a clean, organized interface. It brings together essential storefront elements, including navigation, product discovery sections, promotional content, and footer navigation.

## 🚀 Features

- **Multi-Section Navigation** – Header layout with delivery information, account navigation, search, and cart sections.
- **Interactive Search Interface** – Search bar with category selection and search controls.
- **Promotional Hero Section** – Large banner highlighting featured content.
- **Product Category Showcase** – Eight visually distinct category cards with dedicated imagery and shopping links.
- **Structured Footer** – Organized footer sections for additional navigation.
- **Consistent UI Styling** – Coordinated colors, spacing, typography, and layouts across the homepage.

## ⚙️ Getting Started

### Requirements

- Visual Studio Code
- Live Server extension
- Modern web browser

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/SahitiDasa/amazon-clone.git
```

**2. Navigate to the project directory**

```bash
cd amazon-clone
```

**3. Open the project in VS Code**

```bash
code .
```

**4. Launch the application**

Open `index.html` using Live Server to view the homepage in your browser.
