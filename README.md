# Amazon Homepage Clone

A frontend clone of the Amazon homepage built using HTML and CSS. This project recreates the visual layout of an e-commerce homepage as a beginner frontend development project.

## Preview

The project includes a homepage layout inspired by Amazon, with navigation sections, a hero banner, and product category cards.

## Features

- Amazon-inspired navigation bar
- Search bar layout
- Hero banner section
- Product category cards
- Footer section
- Image-based homepage design

## Technologies Used

- HTML5
- CSS3

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/SahitiDasa/amazon-clone.git
   ```

2. Open the project folder in VS Code.

3. Open `index.html` using the Live Server extension.

## Purpose

This project was created to practice HTML and CSS, understand webpage structure, and improve frontend development skills.
